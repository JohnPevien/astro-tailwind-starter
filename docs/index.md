## Features

- 🚀 **Astro v4+**: Modern static site generator with partial hydration
- 🎨 **Tailwind CSS v3+**: Utility-first CSS framework for rapid UI development
- 🌙 **Dark Mode**: Built-in dark mode support with system preference detection
- 📱 **Responsive Design**: Mobile-first approach with responsive utilities
- 🔧 **TypeScript**: Full TypeScript support with strict type checking
- 🧩 **Reusable Components**: Pre-built components for common UI patterns
- 🔍 **SEO Optimized**: Meta tags, Open Graph, and JSON-LD structured data
- 🚦 **Accessibility**: WCAG 2.1 compliant components
- 📦 **Production Ready**: Optimized builds for deployment
- 🎯 **Developer Experience**: ESLint, Prettier, and comprehensive documentation
